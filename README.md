# 💼 Java Interview Coding Practice

This is my personal revision bank of **frequently asked Java coding interview questions**. These are the programs that come up again and again in service and product company interviews.

I use it for quick revision before interviews. Every problem is solved in plain Java, and where it makes sense also with the **Java 8 Stream API**, because interviewers often ask for both.

## 📂 Categories

| Folder | What's inside |
|---|---|
| `arrays/` | Second largest, missing number, duplicates, rotate array, move zeros |
| `strings/` | Reverse, palindrome, anagram, character frequency, first non-repeating char |
| `java8-streams/` | Group by, frequency map, sort by field, find duplicates using streams |
| `collections/` | HashMap / Set / List based problems |
| `oops/` | Small programs that demonstrate OOP concepts |
| `sql/` | Frequently asked SQL queries (2nd highest salary, duplicates, joins) |

*(Some folders are coming soon. I'm adding to this every week.)*

## ✍️ Format

    /*
     * Q: Find the first non-repeating character in a string
     * Asked in: commonly asked in Java interviews
     * Approach 1: LinkedHashMap frequency count → O(n)
     * Approach 2: Java 8 Streams with groupingBy(LinkedHashMap)
     */

## 🎯 Why this repo exists

Coding rounds for Java developer roles nearly always include a few of these "classic" programs. Having them in one place, with more than one approach for each, makes revising before an interview quick.
